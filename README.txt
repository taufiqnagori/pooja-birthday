POOJA'S MOBILE BIRTHDAY WEBSITE

This is a simple, mobile-first, one-page birthday website. It uses a soft pink theme and a bottom navigation bar. No complicated envelope or page switching.

HOW TO OPEN
1. Extract this ZIP.
2. Open the extracted folder in VS Code.
3. Install the Live Server extension if you do not have it.
4. Right-click index.html and choose "Open with Live Server".

ADD YOUR PHOTOS
1. Open the images folder.
2. Add exactly 3 photos.
3. Rename them exactly:
   pooja-1.jpg
   pooja-2.jpg
   pooja-3.jpg
4. Refresh the browser.

Keep index.html, style.css, script.js and the images folder together.

PUBLISH WITH GITHUB PAGES
1. Create a GitHub repository.
2. Upload all files and the images folder. Keep index.html in the root.
3. Open repository Settings > Pages.
4. Under Build and deployment, select Deploy from a branch.
5. Choose main and /(root), then Save.
6. Wait for GitHub to show the website URL.

The website is designed for phone screens first, but also adapts to desktop.
